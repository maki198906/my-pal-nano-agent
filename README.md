# nanopal 🧠

**nanopal** — минимальный код-фёрст агент на Python (~280 строк), построенный на базе [Nano Harness](https://huggingface.co/learn/context-course/unit6/introduction) из контекстного курса Hugging Face.

Агент получает задачу на естественном языке, вызывает LLM (через OpenRouter), модель генерирует Python-код, который исполняется в изолированном окружении с ограниченным набором инструментов. Результат наблюдения возвращается модели — и так до 50 шагов, пока задача не будет решена.

---

## ⚠️ Важно

Это **учебный инструмент**, а не production-фреймворк.  
`exec()` с фильтрацией builtins **не является** настоящей песочницей — Python-граф объектов (`__class__.__bases__.__subclasses__()`) позволяет обойти фильтрацию. Настоящая изоляция требует отдельного процесса/контейнера.

## 🚀 Быстрый старт

### 1. Установи `uv`

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

### 2. Склонируй репозиторий

```bash
git clone <url-репозитория>
cd my-pal-nano-agent
```

### 3. Настрой ключ OpenRouter

Создай файл `.env` в папке проекта:

```bash
echo 'OPENROUTER_API_KEY=sk-or-ваш-ключ-тут' > .env
```

Ключ можно получить на [openrouter.ai/keys](https://openrouter.ai/keys).

### 4. Установи алиас

```bash
ln -sf "$(pwd)/nanopal.py" ~/.local/bin/nanopal
chmod +x nanopal.py
```

### 5. Запусти

```bash
nanopal "твоя задача"
```

## ⚙️ Как это работает

### Цикл агента

1. **Вызов LLM** — задача + история сообщений отправляются в модель через OpenRouter API
2. **Генерация кода** — модель возвращает Python-код (без prose, без markdown)
3. **Исполнение** — код запускается через `exec()` с ограниченным `exec_globals`
4. **Наблюдение** — stdout, stderr, или `final_answer()` возвращаются модели
5. **Повтор** — до 50 шагов, пока не будет вызвана `final_answer()`

### Инструменты

| Инструмент | Назначение | Безопасность |
|---|---|---|
| `list_dir(path)` | Список файлов в директории | `safe_path()` — только внутри WORKSPACE |
| `read_file(path, max_chars)` | Чтение файла | `safe_path()` + ограничение размера |
| `write_file(path, content)` | Запись файла | Отключён по умолчанию (`ALLOW_WRITE=False`) |
| `exec_cmd(args)` | Запуск shell-команды | Белый список + `cwd=WORKSPACE` + изоляция env |

### Доступные команды

`ls`, `cat`, `pwd`, `echo`, `head`, `tail`, `wc`, `rg`

---

## 🛡️ Безопасность

| Уровень | Защита |
|---|---|
| **Пути** | `safe_path()` — проверяет, что путь внутри `WORKSPACE`, раскрывает symlink через `.resolve()` |
| **Команды** | Белый список бинарников + блокировка `rg --pre` (запуск произвольных команд) |
| **Файловая система** | Запись отключена по умолчанию (`ALLOW_WRITE=False`) |
| **Окружение** | `subprocess.run(env={"PATH": ...})` — секреты не наследуются |
| **Builtins** | Белый список безопасных builtins (без `__import__`, `open`, `exec`, `eval`, `compile`, `input`) |
| **История** | `trim_messages()` — обрезка до 20 сообщений, защита system prompt + задачи |
| **Таймауты** | `TIMEOUT_S=30` на команды и веб-запросы |
| **Retry** | 3 попытки с exponential backoff при сбоях API |

## 🔧 Конфигурация

Все настройки — в начале `nanopal.py`:

| Переменная | По умолчанию | Описание |
|---|---|---|
| `MODEL` | `deepseek/deepseek-v4-flash` | Модель через OpenRouter |
| `MAX_STEPS` | `50` | Максимум шагов цикла |
| `TEMPERATURE` | `0.2` | Температура генерации |
| `TIMEOUT_S` | `30` | Таймаут на команды (сек) |
| `MAX_CHARS` | `8000` | Максимальный размер вывода |
| `ALLOW_WRITE` | `False` | Разрешить запись файлов |
| `MAX_HISTORY` | `20` | Сообщений в истории (помимо system + task) |

Через переменные окружения:

| Переменная | Назначение |
|---|---|
| `OPENROUTER_API_KEY` | Ключ OpenRouter (или `.env` файл) |
| `NANOPAL_MODEL` | Модель (переопределяет `MODEL`) |
| `OPENROUTER_BASE_URL` | Базовый URL API |

## 📦 Зависимости

Управляются через `uv`:

- **PEP 723 inline metadata** в `nanopal.py` — для `uv run --script` (через symlink)
- **`pyproject.toml`** — для `uv sync` и локальной разработки

Зависимости: `openai>=1.0.0`, `rich>=13.0.0`
